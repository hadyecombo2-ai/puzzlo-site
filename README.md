# Puzzlo storefront

Static site for **puzzlo** — Gulf-inspired illustrated jigsaws and metal brain teasers. *Make room for wonder.*

- `index.html`, `styles.css`, `app.js` — storefront (English / Arabic, RTL)
- `products.js` — catalogue. **Sample products and placeholder SAR prices — replace with the real catalogue.**
- `assets/brand/` — logo suite (primary, mono, reversed SVG + PNG) and favicons
- `assets/media/` — hero video (MP4 + WebM, 6 s loop) and poster fallback
- `tools/` — Python generators for the logo, hero video and product images (pycairo + ffmpeg)
